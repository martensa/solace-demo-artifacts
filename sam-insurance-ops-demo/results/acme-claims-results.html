The levers the knowledge base surfaced

Knowledge

The RN-3 lever. 293 of 412 cohort policies (71.1 %) carry the RN-3 repair-network-steering clause. Per PW-RN-3, if no genuine accepted slot (partner + date + time window, not a waiting-list entry) is offered within 5 working days of FNOL, steering lapses to free workshop choice while the discount stays. FNOL ≈ 2026-07-19 (Sunday); 5 working days later = 2026-07-24. From that date the 293 RN-3 claims can be released to free choice, relieving queue pressure without a discount loss.

Knowledge

BaFin clock. Counted from FNOL ≈ 2026-07-19 — the day-20 cohort escalation to the claims lead falls on 2026-08-08; the 30-day CG-BAFIN-30 deadline falls on 2026-08-18. Both dates are before the fastlane/second-shift action closes the queue, so escalation should be logged now regardless of remediation.

How it happened · no prompt, no ticket, no dashboard refresh

Four rules, one Orchestrator, three data technologies, three model tiers

  • Entrypoint

    The claims-events event-mesh entrypoint subscribes to four topic families on the sam VPN and turns each event into a task: fnol/received/minor/> → Fast Lane Clerk; triage/stalled/> → stalled cohort report; weather/cell/forecast/threshold-crossed/> → storm readiness; scanner/mismatch/> → fraud and leakage report. QoS 1, acknowledged only on completion.

  • Fast Lane Clerk

    Answers every MINOR FNOL directly — policy, hail cover HC-7, deductible, drive-in slot, three sentences. Routine, high-volume work on the cheapest model: first confirmation 15 s after the click.fast tier · Haiku 4.5

  • Orchestrator

    Receives the three analysis events, delegates in parallel to the specialists, then merges their findings and writes the report itself — the report skeleton is given inline in the rule, no reporter hop on the event path. The delegation tree is visible in Activities while the audience watches.

  • Query Expert

    Acme Insurance Query Expert — SQL against Postgres acme_insurance: cohort, partner capacity, contract status, exposure, estimates, payment run.general tier · Opus 4.8

  • Knowledge Expert

    Acme Claims Knowledge Expert — semantic search in Qdrant via MCP: policy wordings (RN-3, TL-1), claims guidelines (BaFin 30-day rule, CG-FR-5), partner contracts (second shift, IC-2, RentaFleet, RoadAssist), storm playbook SP-NATCAT-4.general tier · Opus 4.8

  • Intake Analyst

    Storm Intake Analyst — built live in the Builder three minutes before the click — reads MongoDB acme_claims: total-loss signatures, repeat contacts, photo EXIF, channel pairs, scanner results, weather cells.general tier · Opus 4.8

  • Reporters

    Claims Incident Reporter, Storm Readiness Planner and Fraud Case Reporter are the merge step of the workflow variant — stalled-cohort-report, storm-readiness and cross-channel-fraud-report, each with a node output schema. The live event path is Orchestrator-merged: the reports the audience read — root causes, options, the ONE action with the arithmetic shown — were written by the Orchestrator.workflow tier · Sonnet 5

  • Back on the mesh

    Every result is published to acmeins/claims/result/…; the cockpit subscribes and renders it. Approve, Hold and Release publish acmeins/claims/decision/… — the loop closes in the browser, and the human decision is an event like any other.
